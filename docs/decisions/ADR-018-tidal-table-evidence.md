# ADR-018: Data tabel pasang surut Bab 3

Status: Accepted — 2026-10-07.

Pengguna dapat mengunggah gambar, data CSV/XLS/XLSX, atau keduanya untuk field `tide`. Jika data tabel tersimpan, analisis pasut memprioritaskan tabel terbaru; tombol analisis pada gambar pasut juga memakai tabel. Tidak ada fallback diam-diam ke gambar bila tabel bermasalah.

Tabel memakai PhpSpreadsheet yang sudah terpasang, tanpa dependency baru. CSV UTF-8 menerima pemisah koma, titik koma atau tab. Excel membaca worksheet pertama. Baris pertama berisi judul kolom; pengguna memilih kolom tanggal/waktu, tinggi, dan jam terpisah bila ada, format tanggal, satuan m/cm/mm, zona waktu serta acuan tinggi. Default mapping hanya saran; pengguna dapat mengoreksi sebelum menyimpan.

CSV asli SRGI BIG dapat memiliki informasi instansi/stasiun sebelum judul tabel `timestamp_utc,timestamp_local,predicted_height_m`. Reader mengenali pembukaan SRGI dan menemukan judul tabel dalam maksimal 32 baris awal, dengan metadata maksimal 512 karakter per baris. Nama stasiun, koordinat stasiun dan datum disimpan sebagai `tide_file_metadata`; file asli dipertahankan. Informasi kontak tidak diperlukan untuk analisis. Pengecualian ini khusus format SRGI, bukan pencarian judul arbitrer yang dapat membuang sampel dari CSV tanpa header. Formula dan metadata tidak valid ditolak; pesan kesalahan data mengacu pada posisi baris setelah informasi awal.

Untuk format ini, form memilih `timestamp_utc`, zona UTC, format tahun-bulan-hari, tinggi dalam meter dan datum dari file. Pengguna dapat memilih `timestamp_local`, dengan zona sesuai penanda UTC/WIB/WITA/WIT pada setiap nilai; penanda yang berbeda dari pilihan zona ditolak. `timestamp_utc` wajib memakai UTC dan `predicted_height_m` wajib memakai meter. Metadata koordinat stasiun tidak menggantikan koordinat Bab 1 dan tidak membuktikan kecocokan lokasi. `predicted_height_m` menghasilkan `data_kind: prediction`; ringkasan deterministik dan instruksi AI menyatakan data prediksi, bukan pengukuran langsung. Datum MSL yang tercantum pada file adalah acuan tinggi dari sumber, bukan penetapan MSL melalui rata-rata sampel.

Jika file menyediakan kedua kolom timestamp dan penanda zona lokal, form menyinkronkan zona dan kolom secara langsung: memilih UTC memakai `timestamp_utc`, memilih zona lokal memakai `timestamp_local`, dan perubahan kolom memperbarui zona. Zona lokal terdeteksi disimpan sebagai state Livewire terkunci; semua sampel tetap divalidasi oleh analyzer. Zona lain yang tidak cocok dengan kolom file tidak tersedia pada form ini. Kedua kolom memuat tanggal serta jam lengkap, sehingga pilihan jam terpisah dinonaktifkan dan nilai mapping-nya selalu kosong. Pasangan kolom/zona dinormalisasi kembali sebelum penyimpanan untuk menghadapi update field yang tertunda. CSV umum dengan tanggal dan jam terpisah mempertahankan mapping manual.

Aplikasi menghitung jumlah sampel, periode, minimum/maksimum beserta waktunya, rata-rata aritmetika sampel, rentang maksimum-minus-minimum dan interval sampling. Semua tinggi dinormalisasi ke meter. Data kosong, tidak numerik, waktu invalid/duplikat dan rumus ditolak; tidak ada interpolasi atau pembuangan baris invalid diam-diam. Rata-rata sampel tidak disebut MSL. Ekstrem periode tidak disebut HHWL/LLWL/HAT/LAT; tipe pasut dan datum regulasi tidak ditetapkan tanpa analisis yang sesuai.

Batas: file 5 MiB, 50.000 baris data (judul kolom tidak dihitung), 20 kolom, area Excel 200.000 sel, total isi ZIP Excel 32 MiB. Kapasitas ini mencakup data BIG per menit selama 30 hari (43.201 sampel) atau 31 hari (44.641 sampel), termasuk kedua batas waktu, dengan hingga empat kolom Excel. Seluruh sampel dibaca tanpa pemotongan atau pengurangan frekuensi. Excel dibaca bertahap dengan read filter, maksimal 60.000 posisi sel per tahap, agar objek sel tidak menumpuk untuk seluruh bulan; hasil tabel tetap lengkap untuk validasi dan perhitungan lokal. Tabel mentah dilepas setelah perhitungan sebelum validasi penyimpanan berikutnya atau request AI.

XLS/XLSX harus format asli, bukan HTML berganti ekstensi; XLSX dengan macro/tautan data eksternal ditolak; formula ditolak pada semua format, termasuk bagian terakhir tabel. Macro tidak dijalankan. Reader tidak mengevaluasi rumus. Lampiran tetap privat, berbagi kuota Bab 3 (10 file/15 MiB), provenance/koordinat, checksum, akses dan penguncian. Snapshot/revisi mempertahankan metadata; Word/PDF menampilkan ringkasan tabel dan sumber tanpa mencoba merender spreadsheet sebagai PDF.

Perkembangan berikutnya pada [ADR-019](ADR-019-backend-tidal-harmonics.md) menambahkan estimasi harmonik di backend, narasi awal tanpa AI dan tombol AI opsional. Batasan statistik dan datum di atas tetap berlaku.

AI menerima ringkasan perhitungan, bukan seluruh workbook. Narasi pratinjau disertai ringkasan angka deterministik dan sitasi. Payload berubah hanya setelah konfirmasi. Setelah request, akses, lock, identitas tabel, prioritas tabel, koordinat dan checkpoint diperiksa kembali. Kegagalan mempertahankan file dan narasi sebelumnya.

Analisis tabel memakai prompt khusus pasut dengan pratinjau pasut terbaru, metadata sumber, perhitungan lokal dan delapan pesan terakhir. Definisi serta pratinjau field Bab 3 lainnya tidak dikirim untuk tugas ini. Karena statistik sudah dihitung aplikasi, pemanggilan narasi tabel meminta `thinkingLevel: LOW` pada model Flash yang dukungannya terverifikasi (3.8, 3.7, 3.6, 3.5 dan 3 Flash preview). Percakapan umum serta analisis gambar mempertahankan pengaturan sebelumnya; model lain tidak mendapat parameter ini. Gemini 3.8 tidak menerima `MINIMAL`, sehingga nilai tersebut tidak digunakan. Lihat [thinking](https://ai.google.dev/gemini-api/docs/thinking) dan [generateContent ThinkingConfig](https://ai.google.dev/api/generate-content#ThinkingConfig).

Gemini memiliki batas pembentukan koneksi 15 detik dan batas total request 60 detik, dapat diatur melalui `GEMINI_CONNECT_TIMEOUT` dan `GEMINI_TIMEOUT`. Batas total dibatasi 5–120 detik; batas koneksi 1–30 detik dan tidak melebihi batas total. Tidak ada retry otomatis yang menggandakan request berbayar. Error transport membedakan timeout, DNS, verifikasi sertifikat dan koneksi umum. Log hanya menyimpan klasifikasi, kode cURL numerik, durasi serta batas waktu; teks exception, URL, key dan prompt tidak dicatat. Verifikasi sertifikat tetap aktif.

UI menyediakan panel unggah bergaris tepi yang jelas, tombol pilih file, nama file, status unggah, format/batas serta tindakan simpan dan analisis. Pada pasut, panel gambar dan data tabel tersedia bersamaan; keduanya opsional.

Referensi: [PhpSpreadsheet readers](https://phpspreadsheet.readthedocs.io/en/latest/topics/reading-files/), [Excel dates](https://phpspreadsheet.readthedocs.io/en/latest/topics/The%20Dating%20Game/).
