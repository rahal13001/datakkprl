# Retensi data Proposal KKPRL

Dokumen ini adalah kebijakan operasional MVP untuk sistem pendukung penyusunan dan review proposal. Sistem tidak menerbitkan izin dan tidak menjadi sumber keputusan administratif.

- Draft, proposal submitted/needs_revision, revisi, review event, approval, dan edit session disimpan sampai perkara keluarga proposal ditutup dan masa retensi organisasi berakhir.
- Lampiran asli dan artefak Word/PDF berada pada disk privat. Tidak ada URL publik atau penghapusan otomatis pada MVP.
- Snapshot payload, manifest lampiran, dan metadata audit terenkripsi pada database. Review event bersifat append-only.
- Penghapusan, arsip, dan masa retensi final harus mengikuti kebijakan arsip/keamanan informasi organisasi sebelum scheduler penghapusan diaktifkan.
- Request akses, perubahan, dan download harus dicatat melalui log aplikasi/monitoring yang tersedia tanpa merekam nomor HP mentah.
